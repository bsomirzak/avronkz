# Контакты заказов Kaspi

Локальный инструмент: тянет заказы вашего магазина через официальный Kaspi Merchant API
и показывает контакты покупателей в виде таблицы — с поиском, агрегацией по клиентам,
копированием номеров, ссылками на WhatsApp и выгрузкой в CSV.

Токен и данные не покидают вашу машину: браузер ходит на `localhost`, сервер — на `kaspi.kz`.

## Запуск

```bash
cp .env.example .env      # вставьте KASPI_TOKEN
node server.js            # нужен Node 18+, зависимостей нет
```

Откройте http://localhost:8787

Если не хотите класть токен в файл — оставьте `.env` пустым, поле для токена появится в шапке страницы.

## Где взять токен

Веб-версия кабинета продавца → **Настройки → Токен API → «Сформировать»**.
Сформировать может только руководитель компании; токен не меняется, его можно скопировать повторно.

Токен даёт полный доступ к заказам и товарам магазина — не передавайте его никому, кроме своего техспециалиста.

## Что важно знать про данные

| Ситуация | Что приходит |
|---|---|
| Самовывоз, ваша доставка | `customer.cellPhone` — полный номер |
| Часть заказов | номер только в `phoneAlias`, приложение его разбирает |
| Kaspi Доставка | номер часто скрыт — в таблице помечено «скрыт Kaspi» |

Другие ограничения API, которые уже учтены в коде:

- интервал дат в одном запросе — не больше 14 дней, период автоматически режется на окна по 13 дней;
- максимум 100 заказов на страницу, пагинация идёт до конца;
- запрос обязательно фильтруется по состоянию заказа — поэтому статусы выбираются чипами;
- между запросами стоит пауза 220 мс, на 429 и 5xx — повтор с задержкой.

За 90 дней и несколько статусов выгрузка может занять около минуты — это нормально.

## Правовая сторона

Использовать номер для исполнения заказа (позвонить, согласовать доставку) — обычная работа с заказом.
А вот массовые рассылки и реклама по этой базе подпадают под закон РК «О персональных данных и их защите»
и требуют согласия покупателя; за рассылку без согласия отвечает отправитель, а не Kaspi.
Именно поэтому сервисы вроде PriceFeed оформляют это как отдельную услугу с согласием — если планируете
рассылки, имеет смысл сначала разобраться с формулировкой согласия.
