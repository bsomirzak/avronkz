# Документы: счета, накладные З-2, гарантийные талоны, КП, ЭСФ

Раздел **/admin/docs** (закрыт тем же паролем, что /orders: `ORDERS_USER` / `ORDERS_PASSWORD`, см. `proxy.ts`).

| Страница | Что там |
|---|---|
| `/admin/docs` | список, фильтры по ИП / типу / статусу / покупателю / периоду, итог по суммам, смена статуса |
| `/admin/docs/new` | новый документ: ИП → покупатель (поиск или «Вставить реквизиты») → позиции → калькулятор → предпросмотр PDF справа |
| `/admin/docs/<id>` | тот же редактор + «Накладная / Гарантийный талон / КП из этого», «Перевыпустить», «Дублировать», ZIP-пакет, ЭСФ |
| `/admin/docs/buyers` | справочник покупателей |
| `/admin/docs/products` | товары: наименование для печати, характеристики, комплект, гарантия, **поля ЭСФ** |
| `/admin/docs/sellers` | реквизиты ИП, налоговый режим, печати и подписи, счётчики номеров |
| `/admin/docs/settings` | ставка НДС по датам, режимы калькулятора, тексты документов, положение печати/подписи в мм |

## Где что лежит

- `lib/docs/money.ts` — деньги в целых тиынах, НДС (`vatIncluded` = сумма × 16/116, **не** × 16%).
- `lib/docs/calc.ts` — калькулятор «на руки ↔ сумма счёта».
- `lib/docs/words.ts` — сумма прописью.
- `lib/docs/parse.ts` — разбор реквизитов, проверка БИН/ИИН и IBAN.
- `lib/docs/pdf/*` — вёрстка PDF (pdf-lib, шрифт Arimo из `lib/docs/fonts`).
- `lib/docs/esf/*` — выгрузка XML для импорта в ИС ЭСФ, CSV, проверка, адаптер под будущую отправку через API.
- `lib/docs/store.ts` — Upstash Redis, ключи с префиксом `docs:` (`DOCS_PREFIX`).
- Тесты: `npm test` (калькулятор, прописью, парсер, PDF, ЭСФ, нумерация).

## Как добавить ИП

1. В `lib/docs/seed.ts` добавьте запись в `SEED_SELLERS` (id латиницей, реквизиты, режим, `stampKey`/`signKey`).
   Если ИП уже правили в интерфейсе (список лежит в Redis), новый ИП из сидов сам не появится — добавьте его
   там же и нажмите «Сохранить реквизиты ИП» на `/admin/docs/sellers` после деплоя, либо удалите ключ `docs:sellers`.
2. Загрузите печать и подпись (ниже).

## Как загрузить печать или подпись

**Через интерфейс:** `/admin/docs/sellers` → «Загрузить печать / подпись» → фото на белом листе (JPG/PNG/HEIC с iPhone).
Фон удаляется по синему каналу (alpha ≈ B − R, порог — ползунок), картинка обрезается по контуру, поворот 0/90/180/270,
предпросмотр на шахматке → «Сохранить». PNG с уже прозрачным фоном не чистится.

**Скриптом с мака:**
```bash
node scripts/docs-seal.mjs sign stamps/sign_kuandyk.HEIC kuandyk --rotate 270 --upload
node scripts/docs-seal.mjs stamp stamps/stamp_kuandyk.png kuandyk --upload
```
`--upload` кладёт PNG в Redis из `.env.local`. Папка `stamps/` в `.gitignore` — **репозиторий публичный, печати в git не класть.**

Печать и подпись берутся только у ИП, указанного поставщиком (`renderPdf` бросает `SealMismatchError` на чужой ключ).
В документах галочки «С печатью» / «С подписью» по умолчанию выключены.

## Как поменять ставку налога

- **НДС:** `/admin/docs/settings` → «+ Ставка» с датой начала. Документ берёт ставку на свою дату; уже сохранённые не меняются.
- **Упрощёнка / ИПН конкретного ИП:** `/admin/docs/sellers` → «Налоговый режим» и «Ставка, %».
- **Пресеты калькулятора** (упрощёнка 4%, ручной k…): `/admin/docs/settings` → «Режимы калькулятора».

## Как сбросить или сдвинуть номер

`/admin/docs/sellers` → «Нумерация»: там последний выданный номер по каждому типу. Следующий документ получит
«последний + 1», но не меньше уже выданных номеров этого ИП и типа. Номер можно вписать в документе вручную —
при дубле форма покажет «уже занят».

## ЭСФ

- «Проверить» — валидатор: признак происхождения, ТН ВЭД (10 цифр, сочетание с признаком), код ед. изм. (796),
  декларация и позиция для импорта, БИН/ИИН, НДС у неплательщика.
- «XML для импорта» — файл для «ЭСФ → Импорт» на esf.gov.kz (формат InvoiceV2 с изменениями 2026 года:
  `paymentForm`, «без НДС» = нет `ndsRate`). Подписывается ЭЦП уже в ИС ЭСФ. С ошибками XML не выдаётся.
- «Таблица CSV» — поля в порядке формы для ручного переноса.
- Почему ЭСФ падали в «Ошибочный»:
  - *«Код товара (ТН ВЭД ЕАЭС)…»* — у импортного товара (признак 1/2) пустой или неверный код, либо признак 1 у кода не из Перечня изъятий (панели 8528 59…, 8471, мониторы, проекторы, принтеры 8443 — признак **2**).
  - *«Количественную единицу измерения…»* — графа «количественная единица» заполняется только для прослеживаемых товаров (холодильники, стиральные машины, ТВ). Для панелей её надо оставить пустой; выгрузка её не заполняет.
- Не сделано: тег новой графы B9 «дата постановки на учёт по НДС» (нужен актуальный SDK КГД), отправка через API с ЭЦП — точка расширения в `lib/docs/esf/adapter.ts`.
